# Multidimensional Book example files

This directory contains a minimal HBS-KIT example used by reader/preview.html.

Files included:

- manifest.json — describes the books and tag metadata path.
- main_book/main.md — a short main book with a tag placeholder.
- subbooks/sub1.md — the sub-book referenced by the tag.
- metadata/tags.json — tag metadata that links a fragment in the main book to the sub-book.

How to preview:

1. Use the bundled preview page: open reader/preview.html in a browser. The preview page includes the example content and a tiny UI to demonstrate how a tag opens the sub-book content.

2. Or view the files in this examples/ directory directly.
